💡 什么是市赚率（PR）？
市赚率（Price-to-Return Ratio, PR = PE / (ROE × 100)）是价值投资中评估企业“性价比”的高效量化指标。
• PR < 1.0：代表投资者支付的 PE 估值低于其 ROE 水平，具备极佳的安全边际与盈利复利潜力。
• 1.0 ≤ PR ≤ 2.0：代表合理定价区间。
• PR > 2.0：代表高溢价，需观察未来几年是否有极高业绩增速驱动。
